# Backend Removed

This project has been converted to a fully client-side application.
All backend API files have been removed.

The app now runs entirely in the browser using:
- Client-side resume parsing (pdf.js, mammoth.js)
- Client-side job matching engine
- Direct API calls to public job platforms
- localStorage for user data persistence

No server-side code is required. Deploy to any static hosting (Vercel, Netlify, GitHub Pages, etc.).
